# Student Marks Data Processor

CPUF001 Software Foundation development project by Faheem Shehzad.

## Files

- `student_data_processor.py` processes and validates the CSV data.
- `input_data.csv` contains eight sample student records.
- `run_project.bat` runs the project on Windows.
- `run_project.sh` runs the project on macOS or Linux.
- `processed_results.csv` and `processing_report.txt` are generated outputs.
- `Development_Document.docx` is the written submission for Turnitin.

## Run

Windows:

```text
run_project.bat
```

macOS or Linux:

```text
chmod +x run_project.sh
./run_project.sh
```

Direct Python command:

```text
python student_data_processor.py input_data.csv
```

Replace the placeholder GitHub link in the Development Document after uploading
the code to your own assignment repository.
